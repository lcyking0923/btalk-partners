# BTalk Partners

주식회사 비톡파트너스 회사 소개 홈페이지입니다.

현재 사업: 줄기세포 관련 의료기기의 병원 공급, 외국인환자 유치, 통합 마케팅, 콘텐츠 제작.
확장 방향: 디지털·플랫폼, 커머스·유통, 글로벌 파트너십.

사용자가 제공한 회사 소개와 고정된 ‘정관 검토’ 대화의 사업목적 및 영문 상호를 참고했습니다. 설립 관련 개인정보·자본금·개인주소 등은 포함하지 않았습니다. 확장 분야는 현재 실적으로 표현하지 않았습니다.

## 구성

- `dist/index.html`: 회사 소개, 사업 상세, 비전, 연락처
- `dist/styles.css`: 데스크톱·태블릿·모바일 레이아웃
- `dist/site.js`: 모바일 내비게이션, 영상 제어, 언어 전환 로직
- `dist/i18n.js`: 한국어·영어·중국어(간체)·일본어·베트남어 번역 사전 (5개 언어 × 74개 문구)
- `dist/assets/connection-bridge.png`: 생성한 브랜드 콘셉트 이미지
- `dist/assets/*.webp`: 의료기기·글로벌 헬스케어·마케팅·콘텐츠 제작 콘셉트 이미지 4장
- `dist/assets/connection-loop.mp4`: 원본 다리 이미지에 좌우 카메라 이동을 적용한 16초·60fps 무음 배경 영상
- `dist/assets/btalk-brand-film.mp4`: 4개 사업 이미지를 연결한 25초·60fps 무음 소개 영상
- `dist/assets/*poster.webp`: 영상의 실제 첫 프레임과 일치하는 대기 이미지
- `dist/assets/og-image.jpg`: 카카오톡·메신저·SNS 링크 미리보기용 1200×630 공유 이미지(`og:image`)
- `media-prompts.json`: 내장 image_gen으로 생성한 이미지의 정확한 프롬프트와 저장 경로
- `scripts/render-media.py`: 두 MP4 영상을 만든 편집 구성

이미지와 영상은 회사의 실제 제품·임직원·시설·고객 촬영본을 의미하지 않는 콘셉트 자료입니다. 이미지 네 장은 내장 image_gen으로 생성했고, 영상은 이 이미지와 기존 브랜드 이미지에 움직임·문구·전환 효과를 적용해 편집했습니다. 사진은 WebP로 최적화했으며, 영상은 H.264/MP4로 저장했습니다. 음성이나 음악은 포함하지 않습니다.

배경 영상은 음소거로 반복 재생하며 일시정지할 수 있습니다. 움직임 줄이기·데이터 절약 설정에서는 자동 재생하지 않고, 화면 밖으로 이동하면 일시정지합니다. 본문 소개 영상은 사용자가 재생할 때 내려받습니다.

영상은 원본 이미지의 소수점 단위 좌표를 매 프레임 다시 계산해 움직임이 계단식으로 끊기는 현상을 줄였습니다. 배경은 1.08배의 고정 배율에서 부드럽게 좌우로 이동하며, 재생 첫 2초에 약 29픽셀(1440픽셀 너비 기준)의 이동이 보이도록 조정했습니다. 16초 반복의 시작·끝에서 위치와 속도가 이어집니다. 사업 소개 장면의 확대는 1.2~2% 범위이며, 자막은 장면 전환과 분리해 겹치지 않습니다. 대기 이미지와 영상의 비율·구도도 일치시켰습니다. 이미지 속 인물이나 사물을 따로 움직이는 생성 영상은 아닙니다.

## 다국어

헤더 오른쪽의 언어 선택기(한국어 · English · 中文 · 日本語 · Tiếng Việt)로 언어를 바꿀 수 있습니다. 기본 언어는 한국어이며, 처음 방문할 때는 브라우저 언어가 지원 언어와 맞으면 그 언어로 자동 표시됩니다. 사용자가 고른 언어는 브라우저(localStorage)에 저장되어 다음 방문에도 유지되고, 주소에 `?lang=en`처럼 붙어 특정 언어 링크를 공유할 수 있습니다. 우선순위는 `?lang=` → 저장된 선택 → 브라우저 언어 → 한국어입니다.

문구는 `index.html`의 `data-i18n`(텍스트), `data-i18n-html`(줄바꿈·강조 포함), `data-i18n-attr`(aria-label, alt 등) 속성과 `i18n.js`의 키로 연결됩니다. 문구를 고치거나 언어를 추가하려면 `i18n.js`만 수정하면 되고, 새 언어는 `languages`와 `strings`, 필요하면 `fonts`에 항목을 추가합니다. 페이지 제목과 메타 설명, 영상 재생 버튼처럼 JavaScript가 만드는 문구도 함께 바뀝니다. 언어별로 Noto Sans(영어·베트남어), Noto Sans SC(중국어), Noto Sans JP(일본어) 웹폰트를 해당 언어를 고를 때만 불러오고, 줄바꿈 규칙도 언어에 맞게 조정합니다. 브랜드 영상 안의 자막은 영상에 포함된 것이라 바뀌지 않습니다.

빌드 없이 제공되는 정적 홈페이지입니다. `dist` 디렉터리를 HTTP 서버로 제공하면 됩니다. 사업 상세는 JavaScript가 없어도 펼쳐볼 수 있습니다. 폰트를 불러오지 못하면 운영체제의 기본 글꼴을 사용합니다.

연락처 섹션과 푸터에는 사업자등록증 기준의 상호·대표자·사업자등록번호·사업장 주소와 대표 전화·이메일을 표기했습니다. 법인등록번호와 인증·파트너 실적은 넣지 않았으며, 기존 로고를 전달받지 않아 텍스트 로고를 사용했습니다.
